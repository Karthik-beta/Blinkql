Formats Blinkql reads

Blinkql decides a file's format from its extension. Each file you open becomes one table.

FormatExtensionsHow it's read
CSV and TSV.csv, .tsvBlinkql detects the delimiter, the header row and each column's type.
Excel.xlsxThe first sheet becomes the table, with its header row detected.
Parquet.parquetColumns and types come from the file.
JSON.jsonEither an array of objects or one object per line.
JSON Lines.jsonl, .ndjsonOne object per line.

Older Excel workbooks (.xls) can't be read. Open the file in Excel, save it as .xlsx, and import that copy.

Open a file from your computer

There are two ways to open files from your computer:

  • Drag one or more files anywhere onto the workbench. While you drag, the window shows Drop files to import them as tables.
  • Click Import files, the upload icon next to the Tables heading, or choose Import files in the command palette, and pick one or more files.

While a file imports, the sidebar says Importing and the file's name. When it's done, the table appears under Tables with its format, number of columns, size and file name. If a file can't be read, the sidebar says Couldn't import, the file's name and the reason.

Your files aren't uploaded. The browser reads each file where it is, a part at a time as queries need it.

Find a table's name

Blinkql names each table after its file, so you can usually type the name in SQL without quotes. It lowercases the name, drops the extension and replaces spaces and other punctuation with underscores. A name that would start with a digit gets t_ in front, and a name already in use gets a number after it.

FileTable
Orders 2024.csvorders_2024
2026-09 shipments.parquett_2026_09_shipments
a second Orders 2024.csvorders_2024_2

A long name is cut short in the sidebar. Hover over it to see it whole. To see the columns and their types, click the arrow next to the table, or select the table and press →.

Read another sheet of a workbook

An Excel table holds only the workbook's first sheet. When you show its columns, the sidebar shows the call that reads another sheet. For a workbook imported as plants, the file is called plants.xlsx in SQL:

SELECT * FROM read_xlsx('plants.xlsx', sheet = 'Sheet2')

A column's type comes from its first value. If a cell further down doesn't fit that type, such as n/a in a column of numbers, every query on the sheet fails with a message naming the cell. Fix the cell in Excel and import the workbook again, or read every column as text with read_xlsx(…, all_varchar = true). A workbook with a password can't be read. Remove the password in Excel first.

Open a file from the web

To query a CSV, Parquet or JSON file on a web server without downloading it yourself:

  1. Click Add from URL, the link icon next to the Tables heading.
  2. Enter the file's full address, starting with https://. The address must end in the file's name, such as orders.parquet, so Blinkql can tell its format.
  3. Click Add.

Blinkql fetches only the parts of the file a query needs, which makes a large Parquet file quick to inspect. Two things depend on the server:

  • It must let other websites read the file, which is called CORS. If it doesn't, Blinkql says so. Download the file and import it from your computer instead.
  • It should send parts of a file on request. If it can't, Blinkql warns that the whole file is downloaded every time it's read.

Blinkql doesn't keep a copy of a file from the web, so add it again after you reload the page.

Keep files between visits

Blinkql keeps a copy of each file you open from your computer in your browser, in storage that only Blinkql can read. When you come back, your tables are there under the same names. If the browser can't keep a file, for example in some private windows, the sidebar says This browser can't keep these files, so their tables will be gone after a reload.

To remove a table and its kept copy, select the table and press Delete, or click its Forget button, the bin next to its name. Privacy and storage lists everything the browser keeps and how to clear it.

Convert a CSV table to Parquet

A CSV file is parsed again every time a query reads it. Parquet is stored by column, so queries on it are faster and the kept copy is smaller. To convert a table you opened from a CSV or TSV file on your computer, select it and press C, or click its Convert to Parquet button, the two arrows next to its name. The table keeps its name, and the sidebar shows Converting to Parquet… until it's done. The Parquet copy replaces the CSV copy in the browser.

If a file is large for your computer's memory, Blinkql warns you when you import it: This file is large for this device's memory. If queries fail, add a LIMIT, select fewer columns or aggregate. Browser support and limits has more on how large a file Blinkql handles.
