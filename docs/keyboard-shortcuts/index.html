Shortcuts that work anywhere

Only these work wherever focus is. The others on this page belong to the part of the workbench that has focus, so the editor's shortcuts work while you're typing in the editor, and the results table's while a cell is focused. To see this list in the workbench, open the command palette and choose Show keyboard shortcuts.

ActionWindows and LinuxMac
Open the command paletteCtrl+K⌘+K
Close a dialog or the paletteEscEsc
Cancel the running queryEscEsc

On a Mac, the workbench shows keys as symbols: ⌘ is Command, ⌃ is Control, ⌥ is Option and ⇧ is Shift.

Command palette

The palette lists everything the workbench can do. Each command does what its button does.

  1. Press Ctrl+K (⌘+K on a Mac), or select Commands in the header.
  2. Type part of a command's name to narrow the list.
  3. Use ↑ and ↓ to move through the list.
  4. Press Enter to run the command, or Esc to close the palette.

A command that can't run yet stays in the list but is dimmed. For example, the export commands wait until a query has finished. Two commands show a shortcut next to them. Run query is Ctrl+Enter (⌘+Enter on a Mac) and Cancel query is Esc.
