**Queries in the blink of an eye.**

Blinkql is a SQL workbench that runs in your browser. Open a CSV, Parquet or JSON file, write a query and get your results in milliseconds. The engine runs inside the tab, so your files never leave your computer: no account, no server, no upload.

It's built for the exports operations teams live with, such as machine logs, ERP and MES extracts and sensor dumps of 1–2 million rows, and it will ship ready-made analyses for OEE, downtime and shift reporting.

## Status

Blinkql is being built in the open and isn't usable yet. The current milestone is **M0: Foundations**: the project scaffold, CI, deployments, the benchmark harness and these community files. Running queries arrives in M1.

Follow along on the [roadmap](https://github.com/Karthik-beta/Blinkql/wiki/Roadmap-and-Milestones) and in [GitHub Milestones](https://github.com/Karthik-beta/Blinkql/milestones).
